## Content pipeline and trust boundaries

Only a user-submitted explicit generate/make command can enqueue; source text never routes tools. Request count includes cover and references, default7, exact integer5–10. Ranges/conflicting/out-of-range counts fail before enqueue. Theme extracted deterministically from request; model cannot inject code, paths, layout options, hyperlinks or executable actions.

Source selection is explicit and bounded. Last10 user chat statements, ready selected meeting's current analysis/risk/todo snapshots, optional PDF retriever and memory. No automatic newest-meeting guess. Meeting facts retain verified line evidence; risk entries stay analysis, risk_followup todos stay recommendations; edited owner/date/version/status are authoritative saved values, not inferred by model. Snapshot locator holds source/version/page/line IDs. Source limits48 records/36000JSON characters fail visibly rather than silently dropping source sets. Frozen context is retained across retry; issue a new request for changed source data.

Latest external material can invoke the existing Tavily provider using only separately entered publicQuery, never the original PPT/private context. Missing query, off, missing provider and empty result errors do not invent latest facts. Current internal progress alone does not cause pointless search.

Planner gets untrusted JSON data and has no tools. Zod strict schemas enforce total pages, section kinds, max3 items,88-character text and fixed gap messages. Factual quotes must match actual source IDs/text exactly. Inferences must cite source IDs and are labeled analysis; general advice is labeled recommendation. New digits/relative dates and certain internal assertions are blocked in inference/advice. Pattern rules do not prove all semantic truth; actual-deck review is mandatory. Facts use conservative verified extracts rather than unrestricted paraphrase. Unknown owners/dates display “未提供”. Source classification is preserved even when quoting existing risk assessments or followup suggestions.

Renderer owns all coordinates, type sizes, colors and table semantics. 16:9, Microsoft YaHei,42pt cover/32pt titles/20pt body/18pt native tables. No auto-shrinking/auto-added slides. Text capacity validation rejects excess. Reference page lists up to5 chosen sources; every relevant slide note contains full source snapshots/locators, and slide footers contain source IDs. Distinct source claims remain separate. No filesystem access for the model. ZIP normalization removes only unreferenced missing slideMaster declarations emitted by the pinned PptxGenJS version and fixes archive/core timestamps for deterministic hashes.
