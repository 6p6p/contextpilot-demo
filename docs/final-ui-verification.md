# Final UI/UX：对话中心浅色工作台

2026-11-06。本轮只调整 React 前端、样式及浏览器测试，不修改 API、Schema、Prompt、模型/搜索/RAG/会议/记忆/PPT 工作流、任务系统、Storage 或邮件状态。不访问真实凭据，不写 Supabase，不调用付费服务，不 Push/部署。

## 布局和交互

- 260px 浅灰侧栏（窄桌面 240px），品牌、单列图标导航、一个新建会话入口、独立滚动历史。桌面可折叠并本地记住偏好；800px 以下为可关闭的抽屉。
- 白色工作区；顶栏只显示会话/当前页面名、必要的展开/刷新操作。健康时不显示连接成功卡片，异常显示重试；历史成功恢复后清除旧错误。
- 聊天正文最大约800px居中；用户气泡自然宽度、靠右，AI正文无背景大卡片。保留安全 Markdown、表格横向滚动、引用折叠、网页来源和文件下载。
- 历史操作收进独立浮层：重命名、归档会话。保持现有 PATCH/DELETE API 的软归档含义、二次确认、历史证据和文件保留，**没有新增物理删除功能或伪造一个独立删除动作**。浮层不挤压列表，支持外部点击、Escape、箭头/Home/End、键盘焦点，移动端常显三个点。操作菜单不切换会话。
- 输入框为单个圆角容器：附件标签、自动增长输入区、底部加号/紧凑工具状态/圆形上箭头。输入超过上限内部滚动；页面整体不滚动、不用输入框覆盖消息。Enter发送，Shift+Enter换行，composition/isComposing/229防止输入法选词误发，立即锁定防重复提交。
- 加号浮层复用上传PDF、选知识库PDF、指定会议、长期记忆/公共查询授权。原来的联网 off/auto/required、知识库开关及全库/指定PDF设置收进“联网与知识库设置”，不删除任何配置。资料ID、任务请求和来源隔离契约不变；不新增不存在的工具。
- HTTP失败及模型失败保留输入和附件；已入队PPT沿用既有任务状态/快照及安全重试。PPT卡片优先显示关联用户请求标题，历史记录无可用标题时使用非技术文件名或“演示文稿”；页数/阶段/下载照旧，UUID文件名和错误代码在详情，正文显示可读失败原因。
- 知识库、会议/待办/邮件草稿、记忆与PPT历史页共享字体、间距、边框、按钮、空状态和确认弹窗。退出登录仍由原Demo认证组件处理，不修改会话签名或服务端下载保护。

增加 `Icon.tsx` 和轻量 `Popover.tsx`，无新依赖。没有重写业务页面或引入组件库。按 React 最佳实践检查了 Hook 清理、异步作用域、按钮类型/名称、焦点、无障碍标签及布局约束。

## 发现并修复的 UI 问题

1. 旧CSS让历史菜单按钮占整行宽，标题被挤到一个字：限定菜单按钮为30px，并加入标题宽度断言；去掉旧白色按钮块。
2. 旧聊天样式使 Markdown 粗体变小、变绿：覆盖为正文继承，保持文字层级。
3. 移动端菜单 Escape 同时关闭抽屉：菜单先处理按键，抽屉仅在无浮层时响应；展开状态按实际断点计算。
4. 不重挂附件组件来关闭浮层，避免破坏原上传作用域检查；只重置浮层，新增上传未完成时切换会话的回归，确认旧附件不会串入新会话。
5. 既有发送逻辑在模型返回failed时清空输入：前端保留原问题/选定资料，失败消息和后台原状态不改写。
