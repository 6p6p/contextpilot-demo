# 8–12分钟现场讲解

本脚本与自助检查清单共用四个文件。首次空库可直接执行；外部服务处理时间另计，现场可一边等待一边讲解，不假称任务已完成。

| 时间 | 操作 | 讲解重点 |
| --- | --- | --- |
| 0–1分钟 | 登录，说明ORCHID合成场景与共享工作区 | 六项功能围绕同一业务证据；口令线下提供 |
| 1–2分钟 | T01 两轮对话，随后上传三份PDF | 会话上下文；上传处理是后台持久化任务 |
| 2–3分钟 | T02 询问访问码和负责人，展开页码 | 原始PDF可核对，不把无依据答案当成功 |
| 3–5分钟 | T03 上传TXT，核对接口风险，保存人工待办 | 未交付是风险；11-27提议不等于决策；人工字段可编辑 |
| 5–6分钟 | 复核草稿并确认版本；若获授权，单独确认发送一次 | 模型无发送权；展示冻结版本与记录；收件人稍后核实 |
| 6–7分钟 | T04 查看提取完成的记忆，新会话提问并展开来源 | 聊天与会议来源；南京与另一项目苏州不混淆 |
| 7–8分钟 | T05 强制联网问公共Node.js问题 | 真实来源和查询时间；不使用Corpus固定版本答案 |
| 8–10分钟 | T06 选资料发出5页PPT指令 | 不上传新数据，复用人工编辑后的待办和已保存证据 |
| 10–12分钟 | 下载并用PowerPoint/WPS打开；刷新历史；核对邮件收件箱 | 页面完成≠内容验收；供应商接受≠实际收件 |

时间不足时如实标注尚未完成的步骤。邮件未获授权就展示预览，不点击发送；记忆/PPT未完成则演示状态，稍后按清单补验。现场不要清库、运行Corpus脚本、批量重试或展示配置凭据。
