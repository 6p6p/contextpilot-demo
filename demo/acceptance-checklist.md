# 六功能操作与验收

初始状态均为 **NOT_RUN**。每项记录 PASS / FAIL / BLOCKED 和实际证据。以下预期用于判断结果，不保证模型逐字输出相同措辞。全部日期是合成场景历史日期，不要改成今天。

## T01 多轮对话与上下文

1. 新建会话，关闭联网，不选择 PDF/会议，输入：
   > 这是合成项目 ORCHID-7421。总负责人是 Dr. Mira Qiao。林岚于2026-11-06在南京协调试点准备；另一项目ORCHID-FIN的林岚负责财务，地点苏州，时间2026-12-01。请记住并简要复述，不要合并同名人员。
2. 同一会话继续输入：`刚才说的本项目总负责人是谁？本项目林岚何时在哪里做什么？`
3. 刷新并重新打开此会话。

正常结果／通过：负责人、南京／11-06／协调试点准备正确，上下文连续；刷新后两轮消息保留。

## T02 PDF 上传与页码引用

1. 上传 files 中三份 PDF，等待每份处理完成；在聊天附件中明确选择它们。
2. 输入：`根据所选PDF，ORCHID-7421的launch access code、预算、总负责人分别是什么？给出来源及物理页码。`
3. 展开引用，下载/打开原 PDF 核对；再问：`资料是否批准2026-11-27正式上线？`

正常结果／通过：AMBER-593、CNY 137420 来自 rag-project 第2页；Dr. Mira Qiao 来自 rag-owner 第1页或 brief 第1页。引用可回查原文；不得把11-27当作已批准上线。刷新后文件与引用仍保留。

## T03 会议 → 风险 → 人工待办 → 邮件

1. 在会议入口上传 meeting.txt，等待分析完成。
2. 查看风险和证据：第4行供应商接口未交付、可能影响联调；是高风险评估，不是已确认延期。第7行保留11-20试点目标，第8行11-27仅为未批准提议。
3. 找到“复核供应商交付清单”，将周宁／2026-11-08改为**林岚／2026-11-09／进行中**，保存并刷新确认。另一条“补充验收指标”未给负责人和日期，不应补造。
4. 打开邮件草稿，复核内容与已保存待办一致。仅填写已授权且在服务端白名单内的测试收件箱；主题注明“合成演示 ORCHID-7421”。先保存，再确认当前版本。**确认版本不会发送邮件**；未获发信授权在此停止。
5. 获授权的操作者展开“发送此版本…”，逐项核对冻结收件人、主题、正文，勾选确认后点击“确认发送邮件”，仅发送一次。
6. 查看发送历史并“核查供应商状态（不重发）”。由收件人实际打开收件箱核对主题、正文和收件时间，同时检查垃圾邮件目录。

正常结果／通过：风险可回溯行号，人工待办保存后保留；未确认不能发送，修改后须重新确认；只有一个当前版本发送记录。accepted 仅为供应商接受，delivered 仅为对端服务器接受。**真实收件箱收到且内容与冻结版本一致，才完成邮件验收**。记录 delivery ID、Resend ID 和收件人确认结论，不在公开记录中填私人邮箱。

## T04 聊天与会议的跨会话长期记忆

1. T01/T03 完成后，在长期记忆入口等聊天来源、会议来源提取任务完成；检查各有可回溯原文的事实。
2. 新建会话，关闭联网、不选择附件，输入：`ORCHID-7421总负责人是谁？林岚何时在哪里协调试点准备？请引用已保存记忆，不要混入ORCHID-FIN。`
3. 再问：`根据已保存会议记忆，ORCHID-7421保留的试点目标是什么？11月27日是否获批？` 展开来源确认含本轮会议来源，而不是仅凭聊天重复。

正常结果／通过：聊天与会议两类提取已完成；新会话确实召回并引用保存来源。南京／11-06正确；11-20是目标，11-27未批准。刷新后记忆仍在。


## T05 Tavily 实时联网搜索

1. 另建会话，不选附件，选择“强制联网”，输入：`请联网查询 Node.js 当前的 LTS 状态，优先官方来源，给出来源链接和本次查询时间。`
2. 展开来源卡片，打开官方页面核对当前答案；刷新后再次查看来源和时间。

正常结果／通过：真实搜索后有可访问来源、本次查询时间，答案与当时官方内容一致。不预设任何版本号；来源不足时明确说明。界面只能证明检索结果可见，管理员可用供应商控制台/脱敏服务记录进一步核对实际 Tavily 与 DeepSeek 调用，不能以固定快照冒充实时调用。


## T06 对话生成 PPT、下载并打开

1. 新建会话，关闭联网，从附件明确选择本轮三份 PDF 和已完成的会议。
2. 输入：`根据所选PDF和会议，生成5页中文管理层汇报PPT，含封面和参考资料。包括项目概况、交付风险、人工修改后的待办和行动建议。保留AMBER-593、Dr. Mira Qiao、11月20日试点目标、11月27日未批准提议；待办使用已保存的林岚和2026-11-09。区分事实、分析和建议，不得补造进展。`
3. 等待完成，下载 .pptx，用 PowerPoint/WPS 打开并检查5页；刷新网页后再次确认任务可见、可下载。

正常结果／通过：真实5页文件，无修复提示，中文可读，无明显遮挡/溢出；人工待办与未批准提议正确，引用能回查，分析与建议有标记。生成成功不自动证明内容正确，必须实际打开。
